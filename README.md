# TATVA

> Advanced digital forensics and graph intelligence platform for investigating complex financial and cybercrime cases.

<!-- badges placeholder -->

## Overview

TATVA ingests heterogeneous forensic evidence (call records, banking data, GPS logs, emails, FIRs), resolves entity identity across sources, builds an interactive 3D knowledge graph, and generates AI-assisted investigation reports.

## Tech Stack

- **Backend:** Python · FastAPI · PostgreSQL (Supabase) · Neo4j AuraDB · Upstash Redis
- **Frontend:** React 19 · TypeScript · Vite · Tailwind CSS
